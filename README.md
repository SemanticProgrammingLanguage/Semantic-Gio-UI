# Semantic Gio

**Semantic Gio** is a Semantic Programming Language version of the Gio UI framework.

The package was generated by transpiling the original Go implementation of Gio into the **Semantic Programming Language** using the **Universal Code Transpiler**.

## Semantic Programming Language

The Semantic Programming Language provides a canonical semantic representation that can be compiled, transformed and transpiled independently of the original source language.

Semantic Gio demonstrates that an existing Go package can be transformed into Semantic while retaining its semantic program structure.
